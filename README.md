# Estética Conchita · Estilistas Profesionales & Spa

Sitio web de una sola página para Estética Conchita (Aldama 19-B, Tizapán San Ángel, CDMX).

- `index.html` — sitio completo (HTML + CSS + JS, sin dependencias de compilación)
- `assets/` — logotipos e imagen principal

## Ver en local

```bash
node server.js
```

Abre http://localhost:4321
